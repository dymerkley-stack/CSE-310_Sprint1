# Project Title BYU Volleyball Analytics

This project takes player and team data from this past season to find which stats correlate most with winning.
The goal of this software is to find which stats and which players have the biggest impact on winning.
The data was hard to come by and had to be manually entered so the sample size is not the largest but it is 
all of the games from this past season that had player records.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Graphs and generated visualizations are automatically saved to the Outputs/ folder.
2. Install the required Python libraries
3. Run the analytics program from the project directory

Instructions for using the software:

1. Place the BYU player and team CSV data files inside the Data/ folder.
2. Run the program to generate statistical analysis, machine learning predictions, player impact rankings, and visualizations.
3. View generated charts and exported analysis files in the Outputs/ folder.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Python 3.13+
* pandas
* matplotlib
* seaborn
* scikit-learn
